# BugunQilaman
BugunQilaman: oddiy va qulay kunlik reja ilovasi. Bugungi ishlaringizni yozing, bajarish soatini belgilang va tugatganlaringizni belgilab boring. Vaqtida bajarilmagan ishlar qizil bo'lib ko'rinadi. Profilingizda oldingi kunlardagi rejalaringiz va statistikangiz saqlanadi. Telefon va kompyuterda ishlaydi.
